# Strict Figure 3 source export

Generated from frozen strict checkpoints on gpu80 on September 20, 2026.
The exporter does not retrain or select weights using test results. Seeds 31/37/41
use validation-selected joint checkpoints at epochs 70/150/60, respectively.

From a checkout containing the training environment and prepared inputs:

```bash
python tools/export_strict_figure3.py --strict-root /data3/sdz/cgp_align_strict_20260918 --matched-root /data3/sdz/cgp_align_matched_20260919 --encoded-root /data3/sdz/cgp_align_matched_encoded_mean_20260920 --output /data3/sdz/cgp_align_figure3_strict_20260920 --device cuda:0
python tools/verify_figure3_sources.py
```

The output directory must not already exist. These are original server paths;
relocated checkpoint configs and input references must be adjusted consistently.
The exporter requires the adopted matched benchmark embedding archives and Morgan
feature cache in addition to the primary checkpoints and preprocessing arrays.
See `docs/STRICT_MATCHED_BENCHMARK.md` for preceding benchmark stages.

CSV/JSON files are the complete compact source package. Raw per-seed metric JSON,
entity/replicate counts, query-level H hits/ranks, checkpoint hashes, PCA coordinates
and explained variances are supplied. Large latent and ranking NPZ intermediates
remain on the server and are regenerated by the exporter. The saved-source checker
independently uses exact integer combinations for random controls and recomputes
C-E summaries and H aggregates. It does not rerun neural-network inference.

Before joint training, only entity encoders receive pretrained branch weights;
the shared profile encoder is initialized using seed 41. PCA uses the same entity
subset at both stages and a separate full-SVD projection within each stage.
H excludes self matches and resolves ties by ascending gallery index.
