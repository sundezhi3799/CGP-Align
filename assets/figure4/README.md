# Figure 4 source tables

Panels a-d use the relation coverage and benchmark summaries. Panel e displays all 4,017 compound and 5,789 gene coordinates and the same ten reference links, with equal PC1/PC2 scaling. Coordinates and link selection are fixed; label positions are adjusted for readability.

Run `Rscript scripts/plot_figure4.R <output directory>` from the repository root. Dependencies: ggplot2, dplyr, tidyr, readr, patchwork, ggrepel and svglite. Exports are 183 x 175 mm (PDF/SVG and 600-dpi PNG/TIFF).
